# 网页答题助手

Edge / Chrome 浏览器扩展。读取网页里的选择题，可以这样做：

- **导出题目**给大模型（豆包、ChatGPT 等）拿答案
- 拿到答案后**一键自动勾选**
- 也可以让插件自己调模型答题（需配置 API）

纯前端，不需要后端服务。

> 仅适用于你自己的练习、测试环境与已获授权的系统。请遵守所在平台与机构的使用规定。

---

## 为什么用「导出 + 回填」而不是让插件直接答

插件自己答题要分批发请求，25 题大约 10 次 HTTP 往返，耗时 **50–150 秒**。而把题目导出来交给更强的模型，再让插件按答案勾选，全程 **约 10 秒**，判断质量也更好。

| 方式 | 耗时 | 说明 |
|---|---|---|
| 导出题目 → 外部模型 → 回填答案 | ~10 秒 | **推荐** |
| 插件自己调模型 | 50–150 秒 | 需配 API Key |
| 自动答题（含双采样复核） | 50–150 秒 | 最慢，准确率最高 |

## 安装

### 1. 下载

```bash
git clone https://github.com/<你的用户名>/<仓库名>.git
```

或直接下载 ZIP 解压。

### 2. 加载

打开 `edge://extensions/`（Chrome 是 `chrome://extensions/`）：

1. 打开右上角 **开发人员模式**
2. 点 **加载解压缩的扩展**
3. 选择本仓库**根目录**（含 `manifest.json` 的那一层）

> `manifest.json` 必须在根目录。如果套了一层子文件夹，浏览器会提示找不到清单。

### 3. 刷新页面

加载或更新扩展后，**必须刷新一次答题页面**，注入的脚本才会生效。

## 使用

### 推荐流程

```
1. 点工具栏的扩展图标
2. 点「导出题目给豆包」   → 自动复制全部题目
3. 粘贴给豆包 / ChatGPT    → 拿到 «1A 2C 3B …» 形式的答案
4. 粘进插件顶部输入框
5. 点「按答案自动选」      → 页面自动勾选，约 2 秒
```

### 支持的答案格式

以下写法都能识别（已用 12 组用例验证）：

| 输入 | 识别 |
|---|---|
| `1A 2C 3B 4B 5B` | ✓ |
| `1.A` 换行 `2.C` | ✓ |
| `1. A` 换行 `2. C`（点后带空格） | ✓ |
| `第1题 A，第2题 C` | ✓ |
| `1-A 2-C` / `1：A` / `1、A` | ✓ |
| `1A2C3B`（连写无空格） | ✓ |
| `7ABC 8A`（多选） | ✓ |
| `15C 22? 23B`（问号跳过该题） | ✓ |

### 结果反馈

```
✓ 已勾选 24/25 题（页面共 99 个选项节点）
⚠ 未完成：25无答案、22缺D
```

- `无答案` — 你给的答案里没有这一题
- `缺点` — 页面这一题本身没有该选项
- `点不中` — DOM 层面点不动（会把节点路径打印出来）

## 配置模型（可选）

只有「只列答案」「开始答题」「测试模型」需要 API Key。「导出题目」和「按答案自动选」**不需要**。

点「模型设置」，填三项：

| 服务 | Base URL | 模型名 |
|---|---|---|
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat` |
| OpenRouter | `https://openrouter.ai/api/v1` | `openai/gpt-4o-mini` |
| 硅基流动 | `https://api.siliconflow.cn/v1` | `Qwen/Qwen2.5-72B-Instruct` |
| 智谱 | `https://open.bigmodel.cn/api/paas/v4` | `glm-4-flash` |
| 本地 Ollama | `http://127.0.0.1:11434/v1` | `qwen2.5:7b` |

Base URL 只填到 `/v1`（智谱是 `/v4`），**不要**带 `/chat/completions`。

填完点「测试模型」验证连通性。

配置存在 `chrome.storage.local`，不会上传到任何服务器。

## 工作原理

### 题目识别

依次尝试五种策略，按 **题数 × 平均选项数** 打分，取最高分：

1. **表单控件** — `input[type=radio]` / `checkbox` 按 `name` 分组
2. **字母徽标** — 字母单独成圆形节点，选项文字在兄弟节点
3. **字母文本** — 选项以 `A.` `A、` `A)` `A：` 开头
4. **结构推断** — 题干带 `（）` 或 `？`，同级同 class 兄弟节点当选项
5. **纯文本切分** — 只读 `innerText`，按行切题目块与选项

### 按答案勾选

导出题目走 innerText 解析，勾选走 DOM 分组，两条路都刻意做成不依赖特定 class 名：

1. 收集「文本恰好是一个 A–H 字母」的最内层节点
2. 统计每个祖先被多少个字母共享，取共享数 2–12、层级最深者为「选项区」
3. 行 = 选项区里含该字母的直接子节点；按文档顺序编号 = 第 1、2、3… 题
4. 对第 N 题找字母 X 那一行，依次尝试 `input` → `label` → 徽标 → 行本身
5. 每次点击后校验 `checked` / `selected` class / `aria-checked`，未选中则重试，最多 3 次

### iframe 支持

题目常常在 iframe 里，而滚动条属于外层页面。扩展用 `all_frames: true` 注入所有 frame，通过 `chrome.runtime.sendMessage` 广播指令，只让真正含题目的 frame 响应；滚动则 `postMessage` 回顶层执行。

### 排查工具

结构变了、识别不到题时，用这两个按钮取证：

| 按钮 | 输出 |
|---|---|
| **结构探针** | 第一题的 A/B/C/D 各自 DOM 路径、共同祖先在第几层、共同祖先的子节点清单 |
| **导出原始文本** | 每个 frame 的 `innerText` 原文，附单字母元素统计与行首字母统计 |

```

├── popup.html        操作弹窗
├── popup.js          导出题目、按答案选、结构探针
├── options.html      模型设置页
└── options.js
```

## 权限说明

| 权限 | 用途 |
|---|---|
| `storage` | 存模型配置、上一轮结果 |
| `activeTab` | 只在点击扩展时访问当前标签页 |
| `scripting` | 注入抓题与勾选脚本 |
| `<all_urls>` | 扩展要能在任意考试页面工作 |

不收集任何数据，不发遥测，不联网（除了你自己配置的模型 API）。

## 常见问题

**识别不到题目？**
先点「结构探针」，看 `单字母元素总数`。为 0 说明选项字母不是独立元素；有数量但分组失败，把探针输出发到 Issues。

**只识别到部分选项？**
页面可能懒加载，先滚动到底再试。导出时的「选项分布」会告出哪几题不足 4 项。

**更新扩展后没生效？**
`edge://extensions/` 里点「重新加载」，然后**刷新答题页面**。

**弹窗一关就没了？**
浏览器行为，弹窗失去焦点就会关闭。结果已存到 storage，再点图标还能看到。页面上的悬浮窗不受影响。
